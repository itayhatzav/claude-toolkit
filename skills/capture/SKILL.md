argument-hint: "[the thought]"
---
Itay is mid-task. Capture the thought well and get out of the way; budget under a minute.
1. **Where:** the status place the project's CLAUDE.md names (a board or a status file), following its rules file if it has one. A thought about another project goes to that project's place. None named: say so and leave the line in chat.
2. **Ask only if the line would be useless without an answer:** at most two short questions, default zero. A slightly vague line beats a broken flow.
3. **One line per thought:** date, what and why it matters, plain enough to make sense in two weeks with no context, with the trigger when it fits ("saw X while doing Y"). If an existing entry covers it, update that one instead.
4. **Confirm in one line** ("Captured on <where>") and resume the interrupted work without further comment.
Never: read code, weigh options or plan (that comes later, through change or debug); touch code files; write memory.
