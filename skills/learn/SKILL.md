description: Save a durable lesson or rule when Itay says "from now on", "remember", "we learned" or after a QA failure or a correction. Proposes the exact change and saves it in the same turn.
---
1. Classify: project rule (the project's CLAUDE.md), personal working rule (the personal core in Project instructions or this toolkit), fact about the project or Itay (project memory), or a task change (the board).
2. Read the target first and update in place. Never add a line that contradicts an existing one. Check for duplicates.
3. A "from now on" instruction is saved in the same turn. Memory saves need no approval. Changes to a CLAUDE.md or this toolkit are shown as before → after and wait for his yes.
4. If a rule must hold every single time (protects money, data or trust), flag it as a hook or permission candidate instead of only writing a sentence.
5. Keep CLAUDE.md under 200 lines: dated history goes to a log file, not the rule file.
