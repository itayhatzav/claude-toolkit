---
name: assess-idea
description: Assess a new idea, business or project before building anything. Use when Itay says he has an idea, wants to start something new, or asks "is X worth it". Five steps ending in a decision, with evidence.
---
Run in order, short, in chat. Use the `researcher` agent for step 2 only when the question needs dated sources.
1. **Intake.** One sentence: who is it for, what do they pay for, why now. List what Itay already has (skills, accounts, audience, money, hours per week).
2. **Research.** Demand evidence, competitors, how others make money, known failure modes. Dated sources. Never judge from a marketing page alone.
3. **Define.** The smallest version that could earn the first dollar, and the single number that would show it works.
4. **Shape.** Cost (money and Claude usage), time to first result, which steps only Itay can do, and which are gates.
5. **Decide.** Three options at most, one marked recommendation, plus the kill condition (what result means we stop). Itay decides.
Nothing is built or bought during assessment.
